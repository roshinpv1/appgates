Project Summary

The Spring Pet Clinic is a web application built using Spring Boot, utilizing Java as the primary programming language. It features a microservices-based architecture, with separate services for pets, owners, and veterinarians. The application includes key features such as pet registration, owner management, and veterinary appointment scheduling. Testing is performed using JUnit, while logging is handled by Logback. Security measures include Spring Security and OAuth2. Code organization follows the Model-View-Controller (MVC) pattern, with maintainability assessed through the use of dependency injection and loose coupling. Deployment is handled via Kubernetes, with monitoring and observability enabled through Prometheus and Grafana.
